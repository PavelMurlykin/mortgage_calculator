# Руководство пользователя

## Установка и запуск

Приложение работает на Android 7.0 и новее (API 24+). Установите APK из
[Releases](https://github.com/PavelMurlykin/mortgage_calculator/releases) и откройте «Ипотечный калькулятор».

Для сборки откройте проект в Android Studio с поддержкой AGP 8.13.2,
Android SDK 35 (Build Tools 35.0.0) и Eclipse Temurin JDK 21. Проект использует AGP 8.13.2
из `gradle/libs.versions.toml` и Gradle 8.13 из Gradle Wrapper; устанавливать
Gradle отдельно не требуется. После изменения версий выполните в Android Studio
`Sync Project with Gradle Files`. Версия AGP задана ключом `agp` в каталоге версий,
а в файлах сборки плагин подключён через alias.
В настройках Gradle JDK выберите Eclipse Temurin 21; этот JDK также задан
в `gradle/gradle-daemon-jvm.properties`.
Создайте в корне проекта локальный файл `gradle.properties` (он исключён из Git):

```properties
android.useAndroidX=true
org.gradle.jvmargs=-Xmx3072m -XX:MaxMetaspaceSize=1024m -Dfile.encoding=UTF-8
```

В Windows выполните `./gradlew.bat assembleDebug`; в macOS/Linux — `sh ./gradlew assembleDebug`.
Отладочный APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
Установите его на устройство или запустите приложение из Android Studio.
Проверка расчётной логики: `./gradlew.bat testDebugUnitTest` (Windows) или
`sh ./gradlew testDebugUnitTest` (macOS/Linux).

## Расчёт

1. Откройте «Расчет». По умолчанию рассчитывается ежемесячный платёж.
2. Укажите стоимость объекта, первоначальный взнос, срок и годовую процентную ставку.
3. Выберите аннуитетный или дифференцированный тип платежа в карточке результата.
4. Результат обновляется автоматически. Кнопка «График >» открывает платежи по месяцам.

Первоначальный взнос можно менять в рублях или процентах. Значок замка показывает
последнее выбранное представление: оно сохраняется при изменении стоимости объекта.
Срок задаётся в годах либо общем количестве месяцев — это два представления одного
срока, а не складываемые части. Изменение лет задаёт соответствующее число полных лет;
изменение месяцев позволяет указать неполный год. Допустимый срок — от 0 до 30 лет
(360 месяцев). При нулевом сроке платёж равен нулю, график пуст.

Ставки допускают значения от 0 до 100% включительно. Для изменения значений используйте
клавиатуру либо кнопки «−» и «+». Шаг срока равен одному году или одному месяцу.
Денежные результаты показываются в целых рублях; расчёт выполняется без округления до рублей.
Для дифференцированных платежей результат показывает первый платёж соответствующего периода.

В настройках можно выбрать режим «Стоимость объекта». В нём задайте желаемый
ежемесячный платёж, взнос, срок и ставку — приложение определит стоимость объекта.
Сохранение и график доступны в режиме «Ежемесячный платеж».

## Дополнительные параметры

В «Настройки» → «Дополнительные параметры» доступны два переключателя:

- «Скидка/Удорожание» добавляет на экран расчёта корректировку стоимости в рублях
  и процентах. Она действует в режиме «Ежемесячный платеж».
- «Льготный период» добавляет внизу экрана расчёта блоки «Срок льготного периода»
  и «Льготная процентная ставка». По умолчанию переключатель выключен, срок и ставка равны нулю.

Льготный срок задаётся в годах или общем количестве месяцев по тем же правилам, что
основной срок. Он не может превышать срок ипотеки. При сокращении ипотеки льготный
срок автоматически сокращается до её нового срока. Льготная ставка допускает 0–100%
и использует тот же шаг, что основная ставка. Срок и ставка сохраняются при перезапуске.

Если льготный период включён и его срок больше нуля, над основным результатом
отображается «Ежемесячный льготный платеж». Для аннуитета этот платёж рассчитан по
льготной ставке на полный срок ипотеки; после льготного периода остаток долга
пересчитывается по основной ставке на оставшийся срок. Для дифференцированных платежей
основной долг гасится равномерно весь срок, ставка меняется на границе периодов.
«Ежемесячный платеж» показывает первый платёж после льготного периода.

Например, при кредите 1 200 000 ₽ на 24 месяца и льготной ставке 0% на первые
12 месяцев аннуитетный льготный платёж составит 50 000 ₽. Затем оставшиеся
600 000 ₽ распределяются на 12 месяцев с основной ставкой.

Если льготный срок равен всему сроку ипотеки, все платежи льготные, основной платёж
показан как 0 ₽ с пояснением, что после льготного периода платежей нет.
В режиме «Стоимость объекта» заданный платёж относится к первому платежу после
льготного периода, а при льготном периоде на весь срок — к льготному платежу.
При выключенном переключателе или нулевом льготном сроке используется обычный расчёт.
Выключение переключателя сохраняет введённые льготные параметры для повторного включения.

## График, сохранённые расчёты и настройки

В графике нажмите на год, чтобы раскрыть или свернуть его месяцы. Для каждого месяца
показаны платёж и остаток долга. Месяцы льготного периода отмечены словом «Льготный».
Первый платёж относится к следующему месяцу после текущей даты.

Нажмите значок сохранения на экране расчёта. На вкладке «Список» сохранённый расчёт
содержит основные параметры и, при ненулевом действующем льготном сроке, льготный
платёж, срок и ставку. Сроки сохраняются с точностью до месяца. Ранее сохранённые
расчёты продолжают работать без льготного периода. Нажмите название для переименования,
карандаш — для загрузки параметров в «Расчет», корзину — для удаления.
Загрузка восстанавливает также переключатели дополнительных параметров.

В «Настройки» → «Модификаторы» меняются шаг суммы (по умолчанию 100 000 ₽),
платежа (10 000 ₽) и взноса/ставки (0,1%; варианты 1%, 0,1%, 0,01%).
Настройки и текущие вводимые значения сохраняются на устройстве.
